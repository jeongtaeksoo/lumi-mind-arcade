# LUMI’S MIND ARCADE

루미가 실수한 유형을 기억하고 다음 도전을 조율하는 6가지 두뇌 미니게임 브라우저 아케이드입니다. 별도 서버나 프레임워크 없이 HTML, CSS, JavaScript만으로 실행됩니다.

## 플레이 구조

- 5개의 하트로 시작하며 한 라운드는 3개 스테이지입니다.
- 첫 두 라운드에는 `별빛 포착`, `빛 순서`, `균열 탐색`, `궤도 입력`, `신호 전환`, `별길 추적`이 정확히 한 번씩 등장합니다.
- 이후에는 최근 오답과 시간 초과가 많았던 모드를 더 자주 선택하고, 해당 모드의 최근 정확도에 따라 난이도를 한 단계 완화하거나 높입니다.
- 성공 시 남은 시간, 난이도, 직전 콤보를 반영해 점수를 계산합니다. 실패하면 하트가 하나 줄고 콤보가 초기화됩니다.
- 5라운드부터는 최종 사이클을 반복하며 하트가 모두 사라지면 결과 화면으로 이동합니다.
- 모든 시도 결과, 최고 점수, 최고 콤보와 최근 완료 기록은 이 브라우저의 `localStorage`에 저장됩니다. 저장할 수 없는 환경에서는 현재 플레이를 계속하고 결과 화면에 비저장 상태를 명확히 표시합니다.

세부 규칙과 난이도는 [GAME_SPEC.md](./GAME_SPEC.md), 설계 결정은 [확장 설계 문서](./docs/superpowers/specs/2026-08-27-lumi-arcade-expansion-design.md)에 정리되어 있습니다.

## 소리와 자산

- 기존 배경음악 `velvet-tide.mp3`는 홈, `origami-pavements.mp3`는 게임에서 재생합니다. 화면을 이동할 때 두 트랙을 겹치지 않게 정지·전환합니다.
- 음악 토글은 배경음악과 짧은 Web Audio 효과음을 함께 제어하며 설정을 로컬 프로필에 저장합니다. 자동재생이 막히면 첫 홈 상호작용에서 다시 재생을 시도합니다.
- 버튼 프레임과 루미 스프라이트는 저장소의 기존 오리지널 PNG 자산입니다. 원격 글꼴, 아이콘, 음악이나 네트워크 자산은 불러오지 않습니다.
- 두 MP3에는 저장소 안의 출처·라이선스 메타데이터가 없습니다. 기존 제품 동작을 유지하라는 요구에 따라 보존했으며, 공개 배포 전 권리 확인이 필요합니다. 확인되지 않은 라이선스를 임의로 표기하지 않습니다.

## 실행과 검사

```bash
python3 -m http.server 4173
```

`http://localhost:4173`을 브라우저에서 엽니다. 순수 로직 테스트와 구문 검사는 다음과 같이 실행합니다.

```bash
node --test tests/game.test.mjs
node --check app.js
node --check game-core.mjs
```

## GitHub Pages 배포

`.github/workflows/pages.yml`은 `main` 브랜치가 갱신되면 정적 사이트를 배포합니다. 저장소의 **Settings → Pages**에서 **Source: GitHub Actions**를 선택하면 됩니다.
